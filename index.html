Three steps. That's it.

No accounts, no config files, no API keys to hunt down.

1

Install & run

Download, run the installer, and it drops into your system tray. Nothing else to set up.

2

Add to OBS

Copy the overlay URL from the tray menu into a Browser Source. It's already showing what's playing.

3

Go live

Turn on song requests if you want chat to DJ. Everything else just keeps running quietly.

Works with anything

Spotify, Tidal, Apple Music, YouTube Music, browser tabs — anything Windows itself shows media controls for.

Fully customizable

Colors, borders, text — match your stream's theme. Defaults to a clean black & white.

Twitch song requests

Viewers type !sr <song> and it lands in your Spotify queue. They can also use !queue to see what's up next and !nowplaying for the current track. Requires Spotify Premium.

Runs quietly

Lives in your system tray. No console window, single-instance safe, optional auto-start with Windows.

Never goes quiet

When the requests run out, Spotify just carries on with whatever playlist you already had going. Nothing to set up.

Chat announcements & limits

Optional bot posts "now playing" right in your Twitch chat — zero setup. Per-viewer cooldowns keep requests from getting spammed.
