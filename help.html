Help & install notes

Everything you might run into, and what to do about it.

Windows showed a blue "Windows protected your PC" screen

That is Windows SmartScreen, and it appears for any new app that has not been downloaded by many people yet. It is about popularity, not safety.

  1. Click More info.
  2. Click Run anyway.

That is it. You will not see it again on that machine.

It said "Smart App Control blocked an app that may be unsafe"

This is a different, stricter check, and it has no Run anyway button. It is not saying the app is malware. It means Windows cannot verify the publisher, because the installer is not signed with a paid code-signing certificate yet.

Smart App Control is only on by default on fresh Windows 11 installs, so most people never see this.

Every release is submitted to Microsoft for review. Once a build clears, the installer runs normally with nothing needed from you, so the simplest fix is to wait a few days and try again.

Please do not turn Smart App Control off just to run this. You can switch it off under Windows Security, App & browser control, Smart App Control settings. But once it is off, Windows will not let you turn it back on without reinstalling the OS. That is Microsoft's design, not something I can change, and it is not worth losing permanently over one app.

Song requests are not working

Chat-controlled song requests need Spotify Premium. Spotify does not allow apps to control playback on free accounts, so this is a limit on their side rather than a setting you can change.

You will also need to connect your Spotify account once, in the app's settings, and have Spotify actually open and playing on the same machine.

The overlay is not updating in OBS

OBS caches the overlay page. After updating the app, right-click your Browser Source and choose Refresh cache of current page, or restart OBS.

Worth doing the same after you change colors or layout in settings, otherwise OBS keeps showing the old look.

The overlay is cut off

Your OBS Browser Source has its own width and height, separate from the overlay's. If the source is narrower than the widget, the right-hand side gets cropped. Set the Browser Source width to match, or a little wider than, the width you picked in settings.

This is still early software

It has been tested, but you might hit a rough edge here and there. If something breaks, it is not you. Tell me and I will fix it.

The best place to reach me is Twitch, or by opening an issue on GitHub.

Can I support this?

It is free and it will stay free. If you want to throw something in the tip jar anyway, there is a Ko-fi. Entirely optional and very much appreciated.
